# Дино-раскраска

3D-динозавр, которого можно раскрашивать пальцем, как на интерактивной панели в Naturalis.

## Запуск

```bash
./serve.sh
```

Скрипт напечатает адрес вида `http://192.168.x.x:8000`. Откройте его в Safari на iPad (iPad и Mac должны быть в одной Wi‑Fi сети).
Если macOS спросит, разрешить ли входящие подключения для `python3`, нажмите «Разрешить».

Совет: в Safari «Поделиться → На экран „Домой“» — откроется во весь экран, как приложение.

## Управление

- палец по динозавру — рисовать; палец по пустому фону — вращать; два пальца — масштаб
- 🖌️ кисть (3 размера), 🪣 заливка области, 🧽 ластик, ✋ вращение без рисования
- ↩️ отмена, 🗑️ очистить, 📷 сохранить картинку (на iPad — «Сохранить изображение» в Фото)
- раскраска каждого динозавра сохраняется в браузере автоматически

## Устройство

- `dinos.js` — динозавры описаны как поля расстояний (SDF) из плавно слитых эллипсоидов и конусов, сетка строится методом surface nets
- `worker.js` — генерация сетки в фоне
- `grid.js` — сетка по вершинам и треугольникам, чтобы кисть проверяла только то, что рядом с пальцем
- `app.js` — сцена Three.js, раскраска по вершинам, заливка, отмена, сохранение; кадр рисуется только когда что-то изменилось, а разрешение само снижается, если кадров мало
- `vendor/` — локальная копия three.js r160 (интернет на iPad не нужен); импорт в `OrbitControls.js` заменён на относительный путь, потому что import map нет в Safari старше 16.4
